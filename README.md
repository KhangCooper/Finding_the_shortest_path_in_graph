# Finding_the_shortest_path_in_graph
Implement A* algorithm to find the shortest path in the graph using different heuristic function

## How to run

- Download all these files and make sure they are in the same folder.
- To compile these file, using the command:
  
```bash
  g++ main.cpp PathNode.cpp Algo.cpp -o app
```
- To run these file, using the command:

```bash
  ./app.exe
```
